How this works

Every "Check Refund Status" click first checks the cache (Vercel KV here — standing in for the Redis-shaped cache the full design calls for), keyed by return + tax year. A cache hit returns instantly, with no IRS call at all. A cache miss — the first check ever, or the TTL for that return's filing method has elapsed — calls the mock IRS below. A successful call repopulates the cache with a fresh TTL and resets the breaker's failure count to zero. A failing call increments the breaker's consecutive-failure count; at 3 in a row the breaker opens and every subsequent request is short-circuited straight to the last-known-good cached value, marked stale, instead of calling the IRS again.
